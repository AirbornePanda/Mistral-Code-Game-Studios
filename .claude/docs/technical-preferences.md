## Engine & Language

- **Engine**: Godot 4.7.2 (latest stable; 4.8 is beta as of 2026-11)
- **Language**: GDScript
- **Rendering**: Forward+ (desktop; 2D project — 3D can be added later, Forward+ covers both)
- **Physics**: Godot Physics 2D

- **Input Methods**: Keyboard/Mouse, Gamepad

- **Gamepad Support**: Partial
- **Touch Support**: None
- **Platform Notes**: Desktop only. A web target would require the Compatibility renderer (WebGL2) — change `engine.rendering` via /project-settings if that changes.

## Naming Conventions

- **Classes**: PascalCase (e.g., `PlayerController`)
- **Variables**: snake_case (e.g., `move_speed`)
- **Signals/Events**: snake_case past tense (e.g., `health_changed`)
- **Files**: snake_case matching class (e.g., `player_controller.gd`)
- **Scenes/Prefabs**: snake_case matching the file (e.g., `player_controller.tscn`)
- **Constants**: SCREAMING_SNAKE (e.g., `MAX_HEALTH`)
